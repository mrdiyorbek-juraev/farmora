## Prerequisites

- **Node** ≥ 18 and **pnpm** 10.31 (the repo pins `packageManager`).
- A **Clerk** application (auth) and a **Supabase** project (database) — or the Supabase CLI
  for a fully local database.

## Install

```bash
pnpm install
```

This installs the whole monorepo (`apps/*` and `packages/*` via `pnpm-workspace.yaml`).

## Environment

Copy the example env and fill it in for `apps/web`:

```bash
cp apps/web/.env.example apps/web/.env.local
```

<AccordionGroup>
  <Accordion title="Clerk (auth)" icon="key">
    `CLERK_SECRET_KEY`, `CLERK_WEBHOOK_SECRET`, `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`,
    `NEXT_PUBLIC_CLERK_SIGN_IN_URL`, `NEXT_PUBLIC_CLERK_SIGN_UP_URL`,
    `NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL`,
    `NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_REDIRECT_URL`
  </Accordion>
  <Accordion title="Supabase (database)" icon="database">
    `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`

    <Warning>
      The service-role key bypasses RLS. It is used only in server-only code
      (`lib/server/*`). Never import the admin client into a client component.
    </Warning>
  </Accordion>
  <Accordion title="App" icon="globe">
    `NEXT_PUBLIC_WEB_URL`
  </Accordion>
</AccordionGroup>

Env vars are validated at build/runtime with `@t3-oss/env-nextjs` (per-package `keys.ts`).

## Database

Apply migrations to a local Supabase, then regenerate types:

```bash
pnpm --filter @repo/database db:reset    # apply all migrations locally
# or push to a remote:
pnpm --filter @repo/database db:push
```

See [Database](/architecture/database) for the schema and migration conventions.

## Run

<Steps>
  <Step title="Start the web app">
    ```bash
    pnpm --filter web dev      # http://localhost:3000
    ```
  </Step>
  <Step title="Start the docs (this site)">
    ```bash
    pnpm --filter docs dev     # http://localhost:3004
    ```
  </Step>
</Steps>

## Everyday commands

| Task | Command |
| --- | --- |
| Web dev server | `pnpm --filter web dev` |
| Web build | `pnpm --filter web build` |
| Typecheck | `pnpm --filter web typecheck` |
| Format + autofix | `pnpm dlx ultracite fix` |
| Lint (check only) | `pnpm dlx ultracite check` |
| Unit tests | `pnpm --filter web test` |
| E2E tests | `pnpm --filter web test:e2e` |
| New migration | `cd packages/database && pnpm supabase migration new <name>` |

<Note>
  Formatting and most linting are handled by **Ultracite** (Biome under the hood). Run
  `pnpm dlx ultracite fix` before committing.
</Note>
