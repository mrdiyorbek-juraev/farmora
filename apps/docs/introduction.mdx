**Farmora** lets a farm manage its herd: register animals, track their status, weight,
and history over time, and see herd-level metrics — all scoped per organization
(multi-tenant). This is the internal engineering documentation, ground-truthed against the
codebase.

<Info>
  The product surface is `apps/web` (Next.js 16). `apps/docs` (this site) and
  `apps/storybook` are secondary.
</Info>

## Stack at a glance

| Layer | Technology |
| --- | --- |
| Framework | Next.js 16 (App Router + Turbopack), React 19 |
| Auth | Clerk (`@repo/auth`) |
| Database | Supabase / Postgres (`@repo/database`) |
| Server state | TanStack React Query |
| Forms | Formik + Zod |
| UI state | Zustand |
| UI | `@repo/design-system` (shadcn / Radix / Base UI) + Tailwind v4 |
| Monorepo | Turborepo + pnpm |

<Note>
  The "backend" is a set of **server actions** (`app/_actions/*`). There are **no API route
  handlers** in this project — see [Architecture overview](/architecture/overview).
</Note>
